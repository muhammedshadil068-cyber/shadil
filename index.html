UI/UX CASE STUDY

LMS: Softroniics Learning Management System

Project Overview

A learning platform concept designed to help students access courses, learning materials, and academic resources through an intuitive interface. The design removes clutter to allow students to focus directly on learning modules, track progress analytics, and interact with instructional videos without cognitive overload.

Design Process & Methodology
  • User Research: Interviewed students at Softroniics regarding learning bottlenecks and mobile video playback frustrations.
  • Information Architecture: Structured clear hierarchies separating active syllabus modules, assignments, and resource downloads.
  • Design System: Built reusable dark-mode Figma components with high-contrast accessibility (WCAG AA compliant).

MOBILE UI/UX DESIGN

AutoResq: Mechanic Assistance App

Project Overview

A mobile app concept that helps users find nearby mechanics and request roadside vehicle assistance with a simple, user-friendly flow. Designed for high-stress roadside situations where fast one-tap rescue requests, transparent ETA tracking, and verified mechanic profiles are critical.

Key User Experience Solutions
  • Emergency 1-Tap Request: Immediate GPS detection allowing instant roadside tow or mechanic dispatching.
  • User Flow Optimization: Streamlined the breakdown diagnosis questionnaire from 6 screens down to 2 intuitive steps.
  • Live Status Tracking: Clear visual timeline displaying mechanic dispatch, real-time vehicle route, and estimated time of arrival.

LIFESTYLE APP CONCEPT

Blessing: Islamic Tracker

Project Overview

An Islamic lifestyle app concept designed to help users organize worship routines and track personal spiritual goals. The interface combines serene minimalist visuals with habit tracking elements, prayer time countdowns, and daily Quran recitation goals.

Design Philosophy
  • Tranquil Aesthetic: Deep obsidian canvas with gentle emerald and cyan gradient accents that promote calm reflection.
  • Spiritual Habit Tracking: Motivating 14-day streak counters for daily prayers, dhikr repetitions, and charitable actions.
  • Clean Accessibility: High legible typography and uncluttered dashboard widgets tailored for users of all age groups.
